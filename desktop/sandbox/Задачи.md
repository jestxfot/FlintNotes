# Задачи

Задача — строка со скобками. Отметьте её щелчком:

- [x] Открыть FlintNotes
- [ ] Посмотреть все заметки песочницы
- [ ] Завести своё хранилище 📅 2030-01-01
- [ ] Задача с напоминанием ⏰ 2030-01-01 10:00
- [ ] Повторяющееся дело 🔁 every week

Дата пишется после 📅, напоминание — после ⏰. Все открытые задачи хранилища собраны в менеджере задач (`Ctrl+P` → «задачи»).

## Запрос задач

```tasks
not done
path includes Задачи
```
