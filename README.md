# FlintNotes

Заметки в Markdown прямо в браузере. Хранилище — обычная папка с файлами; всё, кроме редактора и списка файлов, включается плагинами.

## Запуск

**Windows:** двойной щелчок по `FlintNotes.bat`. Первый запуск ставит зависимости, дальше приложение собирается и открывается в браузере. Нужен [Node.js](https://nodejs.org) 20 или новее.

**Любая система:**

```bash
npm install
npm run build
npm start                 # http://localhost:4600
```

Заметки лежат в папке `vault` рядом с приложением. Другую папку можно указать при запуске:

```bash
npm start -- "D:/Мои заметки"      # или FlintNotes.bat "D:\Мои заметки"
```

Приложение работает только на этом компьютере: сервер слушает `127.0.0.1` и отклоняет запросы с других сайтов.

## Плагины

Включаются в настройках (`Ctrl+,` → «Плагины»), по умолчанию все выключены. Встроенные лежат в `src/plugins/<имя>/`, свои можно положить в `<хранилище>/.flint/plugins/` (пример: `examples/plugins/hello-world`).

## Разработка

```bash
npm run dev      # http://localhost:5173, правки видны сразу
npm run check    # проверка типов
npm test         # сборка и браузерные тесты (нужен `npx playwright install chromium`)
```

- `server/` — файловый API и слежение за диском
- `src/core/` — ядро: хранилище, индекс заметок, редактор, вкладки, настройки, плагины
- `src/api.ts` — всё, что доступно плагинам
- `src/plugins/` — по папке на функцию
- `e2e/` — тесты
